# Budget & Projets — V1 web mobile

Cette version fusionne :
- budget personnel ;
- entrées / dépenses ;
- projets financiers ;
- checklist mensuelle avec montant libre ;
- projet détaillé type chantier / diaspora ;
- suivi des dépenses projet ;
- matériaux ;
- ouvriers ;
- étapes d'avancement ;
- export / import JSON ;
- stockage local dans le navigateur.

## Tester

Ouvrir simplement `index.html` dans Chrome ou Firefox.

## Limites de cette V1

Les données sont stockées dans `localStorage` du navigateur.
Il n'y a pas encore :
- de compte utilisateur ;
- de synchronisation cloud ;
- de photos ;
- de multi-utilisateur ;
- de PWA installable ;
- d'application Android APK.

## Étape suivante

Transformer cette V1 en PWA installable, puis l'emballer pour Android avec Capacitor.
